Conceptos Fundamentales

Python es un lenguaje de programación de alto nivel conocido por su sintaxis clara y legible, que favorece la productividad y la legibilidad del código.

Alto nivel: Python abstrae los detalles del hardware, permitiendo concentrarse en la lógica de la aplicación en lugar de la gestión de memoria o recursos del sistema.

Interpretado: El código se ejecuta línea por línea por un intérprete, sin necesidad de compilación previa, lo que facilita el desarrollo y depuración.

Multiparadigma: Soporta programación orientada a objetos, estructurada, funcional y aspectos, ofreciendo flexibilidad en el enfoque de desarrollo.

Características Principales

  • Todo es un objeto: En Python, incluso funciones, módulos y tipos primitivos son objetos con propiedades y métodos
  • Tipado dinámico: Las variables pueden cambiar de tipo durante la ejecución sin declaración explícita
  • Gestión automática de memoria: Incluye recolección de basura para liberar recursos no utilizados
  • Comunidad activa: Más de 200,000 paquetes en PyPI para extender funcionalidades
  • Multiplataforma: Corre en Windows, macOS, Linux, e incluso en dispositivos embebidos

Elementos del Lenguaje

Tipos de Datos

Python tiene varios tipos de datos integrados. Los más comunes incluyen:

  • Cadenas (str): Secuencias de caracteres Unicode. Ej: texto = "¡Hola Mundo!"
  • Números (int, float): Enteros y decimales. Ej: edad = 35; precio = 19.99
  • Booleanos (bool): Valores de verdad (True/False). Ej: activo = True
  • Colecciones:
    • Listas: Colecciones ordenadas y mutables [1, "dos", True]
    • Tuplas: Colecciones ordenadas e inmutables (1, "dos", True)
    • Diccionarios: Pares clave-valor {"nombre": "Ana", "edad": 30}
    • Conjuntos: Colecciones no ordenadas de elementos únicos {1, 2, 3}

Estructuras de Control

# Condicional if-elif-else
edad = 18
if edad < 18:
    print("Menor de edad")
elif edad == 18:
    print("Recién cumplido")
else:
    print("Mayor de edad")

# Bucle for
for i in range(5):
    print(f"Valor: {i}")

# Bucle while
contador = 0
while contador < 3:
    print(contador)
    contador += 1

Funciones y Módulos

Funciones Definidas

# Definición básica
def calcular_iva(precio, tasa=0.21):
    """Calcula el IVA de un producto"""
    iva = precio * tasa
    total = precio + iva
    return total

# Llamada a función
total_pagar = calcular_iva(100)
print(f"Total: {total_pagar:.2f}€")

Parámetros:

  • Por omisión: Valores predeterminados para parámetros no obligatorios
  • Keywords: Especificar parámetros por nombre en lugar de posición
  • *args: Recibir múltiples argumentos posicionales como tupla
  • **kwargs: Recibir múltiples argumentos de palabra clave como diccionario

Módulos y Paquetes

Los módulos permiten organizar el código en archivos reutilizables:

  • Módulo: Archivo .py que contiene definiciones y declaraciones
  • Paquete: Directorio que contiene múltiples módulos y un archivo __init__.py
  • Librería estándar: Más de 200 módulos incluidos con Python
# Importar módulo completo

# Importar función específica

Programación Orientada a Objetos

Conceptos Clave

La POO organiza el código en "objetos" que combinan datos y funcionalidad:

  • Clase: Plano para crear objetos (define atributos y métodos)
  • Objeto: Instancia concreta de una clase
  • Atributos: Datos asociados a un objeto (propiedades)
  • Métodos: Funciones asociadas a un objeto (comportamientos)
  • Constructor (__init__): Método especial que inicializa nuevos objetos
  • Herencia: Mecanismo para crear nuevas clases basadas en existentes

Ejemplo Práctico

class Vehiculo:
    def __init__(self, marca, modelo):
        self.marca = marca
        self.modelo = modelo
        self.velocidad = 0

    def acelerar(self, incremento):
        self.velocidad += incremento
        print(f"Acelerando a {self.velocidad} km/h")

    def frenar(self, decremento):
        self.velocidad -= decremento
        print(f"Reduciendo a {self.velocidad} km/h")

class Coche(Vehiculo): # Herencia
    def __init__(self, marca, modelo, num_puertas):
        super().__init__(marca, modelo)
        self.num_puertas = num_puertas

    def abrir_puertas(self):
        print("Abriendo puertas")

# Uso
mi_coche = Coche("Toyota", "Corolla", 4)
mi_coche.acelerar(30)
mi_coche.abrir_puertas()

Trabajo con Archivos

Modos de Apertura

Python permite diferentes modos de acceso a archivos:

  • 'r': Lectura (predeterminado)
  • 'w': Escritura (sobrescribe el archivo existente)
  • 'x': Creación exclusiva (falla si el archivo existe)
  • 'a': Append (agrega al final sin borrar contenido)
  • 'b': Modo binario (imágenes, ejecutables, etc.)
  • 't': Modo texto (predeterminado)
  • '+': Lectura y escritura

Operaciones Básicas

# Escritura básica
with open('datos.txt', 'w') as archivo:
    archivo.write("Línea 1\n")
    archivo.write("Línea 2\n")

# Lectura completa
with open('datos.txt', 'r') as archivo:
    contenido = archivo.read()
    print(contenido)

# Lectura línea por línea
with open('datos.txt', 'r') as archivo:
    for linea in archivo:
        print(linea.strip()))

Manejo de contexto (with): Garantiza que los archivos se cierren correctamente después de su uso, incluso si ocurren excepciones.

Módulos Estándar Útiles

Sistema y OS

  • os: Interacción con el sistema operativo (archivos, directorios, variables de entorno)
  • sys: Acceso a parámetros del intérprete y funcionalidades del sistema
  • subprocess: Ejecución de procesos externos y comandos del sistema
  • shutil: Operaciones de alto nivel en archivos y colecciones de archivos

Desarrollo

  • datetime: Manipulación de fechas y horas
  • json: Codificación y decodificación de datos JSON
  • re: Operaciones con expresiones regulares
  • logging: Sistema flexible de registro de eventos

Internet y Redes

  • urllib: Manejo de URLs y solicitudes HTTP
  • socket: Interfaz de bajo nivel para comunicaciones de red
  • smtplib: Cliente SMTP para enviar correos electrónicos
  • http.server: Servidores HTTP básicos

Utilidades

  • random: Generación de números pseudoaleatorios
  • math: Funciones matemáticas y constantes
  • itertools: Funciones para crear iteradores eficientes
  • collections: Contenedores especializados de datos
