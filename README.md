# Guía de Estudio: Python para Principiantes

Este proyecto contiene una guía interactiva en formato HTML para aprender Python desde cero.

## Ver en línea

👉 [Haz clic aquí para ver la guía en GitHub Pages](https://<TU_USUARIO>.github.io/guia-python)

## Instrucciones

1. Sube los archivos de este repositorio a tu cuenta de GitHub.
2. Activa GitHub Pages desde la pestaña "Pages" en la configuración del repositorio.
3. Asegúrate de seleccionar la rama `main` y carpeta `/ (root)` como fuente.
4. ¡Listo! Tu guía estará disponible en la web.
